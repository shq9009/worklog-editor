🔑 首次使用：配置 GitHub 令牌

★ 令牌只保存在你本机浏览器的 localStorage，不上传给任何第三方；权限建议只给 worklog 这一个仓库。
  1. 打开 GitHub 令牌创建页（点我）
  2. Token name 随意（如 worklog），Expiration 建议 90 天或 1 年
  3. Repository access 选 Only select repositories → 只勾 worklog
  4. Permissions → Repository permissions → Contents: Read and write
  5. Generate token，复制以 github_pat_ 开头的令牌，粘贴到下面 ↓
